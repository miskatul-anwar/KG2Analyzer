# Identity links are discovered by default when a delivery is ingested

The input is a set of KGs that rarely ships with owl:sameAs links, and without them cross-KG analytics have nothing to join on. So `ingest` scores candidates for every pair of KGs and adds those with score >= 0.6 to the identity graph. The links are explicit triples in the inspectable identity graph, never inferred at query time, so the explicit identity invariant holds, and each added link is listed in the pipeline report. On the enterprise benchmark, with no links supplied, this recovers all 12 pairs of the 4 entity clusters with precision 1.0. The next-best candidate scores 0.24. Evaluation counts pairs implied by transitivity as correct, because owl:sameAs is transitive. Callers who need hand-curated identity only pass `auto_link=False` (`--no-link`).
